Receipts and evidence

What has been shown, what has not, and where each claim's record lives. Dated evidence and named limits, no adjectives. Nothing on this page is called golden without the owner's explicit word.

What is proven, and what is not

Proven

  • The probe machinery works end to end on synthetic cases: declarations, sealed expectations, blind execution, contradiction detection and classification, audit hardening, public receipts.
  • An audit leg with an opposing brief catches errors in the advisor's own record, not just the executor's output. This is the mechanism that beats sycophancy: roles with opposing briefs produce friction by construction.
  • The mechanism probes detect their targets on deterministic synthetic cases.
  • The chain-of-thought faithfulness instrument is not rigged. An informed positive control scores faithful on it.
  • The medical evaluation-integrity detector, version 2, is clean on its bench under independent blind review.

Not proven

  • Anything about real substrates. No evidence on true concurrency, scheduler preemption, power loss, crash durability, or production behavior. The bench gives none.
  • Two ground-truth probes are verified but not golden. Built and blind-checker-verified; not owner-accepted.
  • The chain-of-thought story-pair claim is unmade. The blind track has not run and the owner has not adjudicated.
  • The medical detector is unaccepted and unpublished.
  • The V=IR mapping and the simplification thesis are crosswalks and analogies with a stated claim frame, not empirically validated laws.
  • Nothing has been independently replicated.

Minted gold

Public · MIT · minted gold by owner decision 2026-09-23

pilot-001: a parallel advisor system

An eval-of-evals harness. It does not grade models. It grades the eval: were the answers locked before the run, did two independent parties reproduce them, what happened when they disagreed, and can a stranger re-run the whole thing.

The first clause ran the full course: declaration, sealed expectations, blind two-track execution on two operating systems, a contradiction found and classified and resolved on the record, the detector hardened by an independent audit, re-audit, public receipts, and the judge's mint. The audit leg caught an error in the advisor's own record, not just executor output.

What it does not prove: that the executors are smart, honest in general, or aligned. This pilot was deterministic. It proves the machinery, not the models. Judgment-based tasks, where an executor could actually drift, are the stated next frontier.

A failure and its repair

The earlier Gap Check detector counted cancelled human review as oversight. This input now produces an oversight-gap finding:

Our autonomous agent can execute production changes.
Human review was never implemented.

The shared engine now checks cancellation in everyday-language phrases as well as aliases. The regression cases also preserve genuine review and keep nearby risks visible.

Reproduce the checks

From a repository checkout with Node.js installed, record the commit and run:

git rev-parse HEAD
node gapcheck-corpus.js
node coherence-audit-corpus.js
node continuity-audit-corpus.js

These checks need no package installation or model API. For the broader suite and its runtime requirements, inspect the CI workflow. To check that the numbers on this site still trace to the repository, run Pin-Check against a checkout with stylesheets and pages in scope. This is the exact command behind the recorded clean run:

python skills/pin-check/pin_check.py index.html . --ext=.md,.py,.json,.js,.mjs,.txt,.yml,.yaml,.cff,.css,.html

With the tool's default extensions the same run reports one CSS color code and one HTML entity code as undefined, because stylesheets and pages are not read by default. The flag brings them into scope; the calibration log records both runs.
