A failure and its repair

The earlier Gap Check detector counted cancelled human review as oversight. This input now produces an oversight-gap finding:

Our autonomous agent can execute production changes.
Human review was never implemented.

The shared engine now checks cancellation in everyday-language phrases as well as aliases. The regression cases also preserve genuine review and keep nearby risks visible.

Reproduce the checks

From a repository checkout with Node.js installed, record the commit and run:

git rev-parse HEAD
node gapcheck-corpus.js
node coherence-audit-corpus.js
node continuity-audit-corpus.js

These checks need no package installation or model API. For the broader suite and its runtime requirements, inspect the CI workflow.
