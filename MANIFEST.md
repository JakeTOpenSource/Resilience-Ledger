## Issue Label System

For consistent governance tracking, use these labels:

### Decision Type
- `governance-decision` - Standard agentic decisions
- `human-override` - Human interventions
- `incoherence-report` - Inconsistency reports
- `cost-analysis` - Resource tracking

### Implementation Phase
- `phase:foundation` - Initial setup
- `phase:deployment` - Active use
- `phase:optimization` - Improvements

### Priority Level
- `priority:high` - Requires immediate attention
- `priority:medium` - Standard timeline
- `priority:low` - Can wait

### Status
- `status:pending` - Awaiting review
- `status:approved` - Ready for implementation
- `status:implemented` - Completed
- `status:review` - Under assessment

## Metrics and Monitoring

### Key Indicators
- **Decision Volume:** Issues created per period
- **Review Time:** Hours from creation to approval
- **Override Rate:** Human overrides vs. total decisions
- **Cost Efficiency:** Average cost per decision
- **Incoherence Rate:** Reported inconsistencies per decision

### Audit Trail
All decisions are permanently recorded in GitHub Issues:
- Timestamp of every change
- Creator and reviewer attribution
- Complete decision rationale
- Cost documentation
- Outcome tracking
