# Decision 0004: STP v1.2 public reproduction release

**Date:** 2026-08-12

**Decision:** ACCEPT_WITH_LIMITS

**Consequence class:** C2

**Authorization evidence:** the authenticated repository owner reviewed and
accepted the bounded candidate work and directed its privacy-minimized public
release

**Cryptographic signature:** not present

## Accepted public set

The owner authorizes publication of the exact normalized file identities in
`research/stp-v1.2/release-manifest.json`, comprising:

- proposed technical profiles;
- pinned schemas and validation dependencies;
- invented synthetic conformance fixtures;
- JavaScript and Python reference reducers and offline validators;
- a public primary-source register; and
- plain technical documentation and explicit claim ceilings.

The manifest is an allowlist. An unlisted file is not part of this decision.

## Required boundary

The release contains no private artifact bytes or digests, private source code,
private repository identifiers, absolute local paths, prompts, transcripts,
credentials, screenshots, private analytics, or internal development journal.
The privacy gate must compare the complete release tree with the manifest and
reject forbidden path and credential patterns.

## Limits

This decision accepts publication of a reproducible candidate packet. It does
not accept STP v1.2 as a protocol release, supersede STP v1.1, authorize a live
instrument, establish source truth, prove an external event occurred, establish
statistical reliability, or prove unbounded safety or liveness. `PASS`, `FAIL`,
and `UNKNOWN` in the packet are typed synthetic conformance outcomes, not a
model-belief score.

Repository checks and the protected pull-request path remain mandatory. A
future correction or expansion requires a new decision and a new manifest; it
must not silently rewrite this release record.
