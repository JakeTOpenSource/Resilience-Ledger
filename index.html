Framework

BespokeNode

A governance framework for agentic AI. Nothing an agent does counts until it has been defined, permitted, gated, verified and accepted, in that order, by the right party at each step. Two safety states, HOLD and TRIP, each with its own recovery path. Four invariants that never bend.

Run it now

pilot-001 is the first clause run through the framework end to end: sealed expectations, blind two-track execution, a contradiction found and resolved on the record, an independent audit that attacked the checker, and public receipts a stranger can re-run. MIT licensed.

The same discipline governs this site's own changes: every proposed change is a state-delta in a register, sorted by a human with a written reason. Read how the register works.

Skill

Pin-Check

Every precise number in a technical document came from somewhere. Pin-Check reads a document, pulls out every value precise enough that it must have a source, and looks for that source under a directory you name. Each value comes back traced, rounded, or currently undefined.

Run it now 
python skills/pin-check/pin_check.py <document> <root>

Python 3, standard library only, no install, no network. Exit code 0 when everything traces, 1 when anything does not. The README explains each result, including the copy-detection step to read before trusting a clean run.

Receipt

This home page and the architecture page were run through Pin-Check against this repository before publication. The calibration log records the run. The tool finds broken links between prose and artifacts, not bad math.

Method

OpenMirror

A method for turning a metaphor into policy one correspondence at a time. The analogy is treated as a one-to-one mirror: verification is correspondence by correspondence, and a break at any joint is a precise, located failure rather than a reason to throw the analogy away.

Run it now

The Bridge Card is the one-minute form of the method. Six fields: SOURCE, CLAIM, OPEN TERMS, PARALLEL, HINGE, STATUS. Copy it into any assistant as a custom instruction or fill it by hand. It ends in accept, not yet, or a named uncertainty.

Receipt

The worked example is the V=IR crosswalk: authority as voltage, effects as current, the gate as resistance. The author reports red-teaming it against a first draft; those notes are not yet published. It is a crosswalk with a stated claim frame, not an empirically validated law.

What is proven, and what is not

Proven

  • The probe machinery works end to end on synthetic cases: declarations, sealed expectations, blind execution, contradiction detection, audit hardening, public receipts.
  • An audit leg with an opposing brief catches errors in the advisor's own record, not just the executor's. Roles with opposing briefs produce friction by construction.
  • The mechanism probes detect their targets on deterministic synthetic cases.

Not proven

  • Anything about real substrates. No evidence on true concurrency, scheduler preemption, power loss, crash durability, or production behavior.
  • The V=IR mapping and the simplification thesis are crosswalks with a stated claim frame, not validated laws.
  • Nothing has been independently replicated.
